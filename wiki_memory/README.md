# 项目记忆入口

本目录是“牡丹真国色”网页工程的持久记忆，采用附件提供的 Markdown 工程记忆架构。根目录按用户要求命名为 wiki_memory。源代码、现有文档、用户提供的分镜和内容文件仍是事实来源；本目录只记录面向后续工作的摘要和索引。

## 会话开始时

按 [[AGENTS|记忆维护协议]]，依次读取项目概览、系统架构、当前约束、当前待办，以及与任务相关的 active 决策。必要时再读相关知识页和最近日志。
