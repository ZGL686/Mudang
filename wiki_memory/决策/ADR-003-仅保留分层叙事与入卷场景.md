# ADR-003：仅保留分层叙事与入卷场景

## 用户要求

用户2026-10-08明确要求深度清理，只保留截图中的分层叙事预览与约2分钟入卷场景，并补充清除冗余、旧站压缩产物和无用代码。两张截图分别为StoryPage封面和进入后的播放状态。

## 决定

- 继续使用React + Vite，源码统一source。唯一应用为StoryPage + useStoryPlayer + Canvas 2D渲染器，保留六场18镜、119秒原文时间线与制作状态。
- 默认index.html直接展示分层封面。experience.html兼容原预览地址，两者共用source/main.jsx和同一构建JS/CSS；删除重复source/story.jsx及返回旧主站链接。
- 保留截图播放器的播放/暂停、进度、章节、环境声、读花史原文弹窗、结束重播及现有指针交互。
- 删除旧WebGL主站与独立阅读页、编译引擎、模型/字体/纹理/场景视频/转码器、专用制作与检查脚本、旧实现归档和重复QA。只迁移播放器仍引用的环境声及纸纹至public/assets/story。
- public仅发布当前33张图层、环境声和纸纹。保留支持故事的用户原文、原图、分层底稿、提示词和参考视频。
- 旧实现与QA通过Git提交2b6d5e8追溯，wiki历史日志不改写。新检查报告写docs/qa/current，可重建帧、视频和接触表由Git忽略。

保留兼容HTML地址、修正低高度横屏封面按钮及按钮焦点下的方向键属于本轮常规实现选择。

## 验证与边界

依照npm lint/check/build及当前浏览器检查报告验证。artReady仍全部为false；清理不宣称完成美术、真实设备、音频听感或素材授权验收。Git沿用[[决策/ADR-001-按对话提交并推送]]。
