# React 与 Vite 架构及目录整改

## 目标与确认决策

按用户要求，以回退后的 9744849 工程为基线，将架构迁移到 React + Vite，以 `source/` 管理源码，消除 `网页/网页` 嵌套并整理原始资料、运行素材、工具与历史记录。用户明确选择的架构与源码目录写入 [[决策/ADR-002-React与Vite及标准目录]]。

## 工程变更

- 增加 React 双入口、Vite 开发和生产构建、依赖锁文件、ESLint、编辑器与 Node 版本配置。
- 主入口拆为画布、六场阅读、导航和单文档引擎适配组件；分层预览由 React 管理加载、播放、章节、逐字正文、阅读、音频、输入与生命周期。
- Canvas 引擎五模块保留；WebGL 编译引擎使用确定性资源路径与启动诊断适配，删除活动页面中无关的商城、账户、Cookie 和支付结构。
- 运行素材归入 `public/assets`，原文、40 张参考图、制作底稿和提示词归入 `materials`。原 ZIP、解包目录和站点快照归入被忽略的 `materials/local`，本地缓存归入 `.cache`。
- 制作、数据与 QA 工具归入 `scripts`，移除工作站 Node 缓存路径。Python 解释器支持环境配置；机器路径仅在忽略的 `.env.local`。
- 历史记录、旧 HTML/播放器/服务脚本归档于 `docs`，新增根 README、目录和工具说明。283 个已跟踪文件逐项与 Git 基线核对摘要，200 个二进制文件内容保持，映射在 `docs/qa/react-migration/file-moves.json`。
- 修正迁移中发现的旧样式透明导航、不可点击重看链接、负边距遮挡、缺失字体格式与旧纸纹理路径；减少动态模式跳过开场黑色遮罩，时间仍从零开始。

## 检查范围与结果

- npm lint、目录/资源检查、119 秒 18 镜时间线、React 实际组件静态渲染检查通过。
- 确定性引擎适配、22 项资源与 26 个遮罩检查通过；33 张分层运行图与 24 份场景视频存在。
- 原文数据提取与时间线重建已运行；除资料路径外，逐镜文案、镜头、时序和制作状态保持。
- 生产构建通过且无缺失资源警告；离线渲染完成，记录在 `docs/qa/current`。
- 浏览器实测双入口、播放暂停、章节、阅读、结束重播、390像素窄屏和 /mudang/ 子目录部署；范围与结果在 `docs/qa/react-migration/browser-review.json`，逐项架构审计在同目录 completion-audit.md。
- npm ci 在停止占用原生依赖的预览进程后成功，依赖审计为零漏洞。最终审阅修正制作来源清单路径、重看按钮定位及开发热更新状态同步。

## 遗留与下一步

原 WebGL 在内置浏览器仍出现纸色空白，本轮未确认目标浏览器根因；界面导航与独立阅读保留可用。真实手机、声音听感、完整逐帧美术和素材授权仍沿用原待办。本轮交付仅证明架构、目录、构建及记录范围内的交互迁移。

## 待确认长期记忆

无新增未确认架构主张。React + Vite、source 统一源码和目录整改由用户在本轮明确要求；后续可按实际制作继续拆分第三方图形实现。
