# 2026-10-03｜主入口与分层预览互通

- 时间：2026-10-03（北京时间）
- 类型：feature
- 状态：双向导航已实现；目标浏览器和预览画面仍未验收
- 目标：保留原 WebGL 主入口，同时让制作预览可从主页面打开，并可返回主页面。

## 已确认的实现边界

- `index.html` 继续保留原站交互；`experience.html` 仍是独立的 Canvas 2D 分层预览，不替换主入口。
- 主入口加载页和“六场花史”阅读区均提供预览入口，预览页顶部返回 `index.html#read-story`。
- 返回链接在播放器脚本加载后立即绑定，不等待预览素材全部解码，加载期间也能离开。

## 文件变更

- `网页/网页/index.html`、`网页/网页/peony.css`：加入并设置启动页和阅读区的预览入口样式。
- `网页/网页/experience.html`、`网页/网页/story.css`：加入顶部返回链接及响应式样式。
- `网页/网页/story-player.mjs`：把返回处理器移到模块初始化阶段，保留中键和修饰键的浏览器默认行为。
- `网页/网页/README.md`：说明两个入口的关系。
- `wiki_memory/当前状态/`、`wiki_memory/日志/MOC_工作日志.md`：同步入口架构、当前待办、浏览器边界并登记本日志。

## 检查与结果

- PASS：本地浏览器中从主页面故事区激活预览 CTA，最终到达 `experience.html`。
- PASS：当预览页入卷按钮仍为禁用状态时，点击顶部返回链接仍到达 `index.html#read-story`。
- PASS：本任务前段的启动加载页 CTA 点击曾到达 `experience.html`。
- PASS：`node --check story-player.mjs`；`memory_lint.py index` 与 `memory_lint.py check`，20 篇 Markdown 页面通过。
- 未验证：Codex 浏览器直接加载 `#read-story` 时页面未滚到故事区；主页面仍处于原 WebGL 空白问题的验收边界内。
- 未验证：本轮 `experience.html` 入卷按钮持续显示“墨色正在晕开…”且错误文字为空，预览画面没有完成验收；加载或解码阻塞原因待查。
- 未验证：真实手机触控、支持 WebGL 的目标桌面浏览器和正式参赛材料。

## 结果、遗留项与下一步

- 结果：两种实现已有明确的双向导航路径；返回入口不再依赖预览引擎先完成初始化。
- 遗留项：主入口滚动到阅读区的可达性、主入口 WebGL 场景、预览素材加载状态均未在目标设备验收。
- 下一步：在支持 WebGL 的桌面浏览器检查主入口滚动与故事区入口；检查预览资源请求和图像解码等待，再复测 2D 预览。
- 待确认长期记忆：无新架构决策候选；本轮仅更新现有 active 状态页的已验证事实。
- Git：当前 `D:\网页-数媒大赛` 不是 Git 仓库，且没有可核对的 GitHub remote；依据 ADR-001 未初始化仓库或猜测远程地址，因此本轮不能提交或推送。
