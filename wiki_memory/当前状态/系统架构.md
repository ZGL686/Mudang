# 系统架构

## 应用入口

index.html 与兼容地址 experience.html → source/main.jsx → features/story/StoryPage + useStoryPlayer。唯一应用管理加载、分层封面、119秒播放、六场跳转、逐字正文、读花史弹窗、音频、滚轮/键盘/指针与生命周期，调用 engine/story-renderer.mjs 及core/pavilion/spring/transition模块绘图。?shot=1..18&at=秒保留定位预览。

source/data/story-timeline.json、story-layer-manifest.json 和 source-documents.json 为业务数据。36个图层映射对应public/assets/story/layers的33张PNG；环境声在audio/ambient.mp3，纸纹在textures/paper.jpg。source/lib/asset-url.js 管理Vite相对部署基址。

## 生命周期与构建

唯一应用使用StrictMode，取消异步图像加载、RAF与事件并释放音频和画布。旧WebGL全局引擎及专用整页热重载插件已删除，使用Vite标准React热更新。

Vite将两个兼容HTML与同一JS/CSS构建到dist；默认相对base，开发5173、预览4173，暂无自动生产部署。旧静态服务器及旧实现归档已删除。

## 目录与制作

materials/documents、images/story-originals、artwork/layer-drafts、prompts/story、references保存保留叙事的制作来源；旧WebGL底稿已删除。scripts/{data,qa,lib}定位根工程并使用项目依赖。Python通过环境或.env.local配置，图片提取仅需Pillow。

当前检查报告在docs/qa/current。旧QA与迁移映射已清理，从Git提交2b6d5e8追溯；历史日志不改写。可重建的离线画面、连续帧与接触表由.gitignore排除。当前结构见docs/STRUCTURE.md。
