# 系统架构

## 架构概览

工程根目录保存源文档和素材；可运行网页位于 网页/网页/。网页有两条实现路径：index.html 延续参考站的 WebGL 长卷交互，experience.html 使用独立的 Canvas 2D 分层故事渲染器进行制作预览。主入口的启动加载页及六场阅读区可跳转至分层预览，预览页顶部可返回 index.html#read-story；浏览器完成了导航点击验证，但主入口 WebGL 与用户滚动可达性仍未验收。

## 模块关系

| 模块 | 职责 | 依赖 | 入口 |
| --- | --- | --- | --- |
| 原交互网页 | 长卷显影、场景过渡、鼠标/滚动交互 | 本地 WordPress 风格资源、模型、图集遮罩、视频 | 网页/网页/index.html |
| 分层故事播放器 | 播放 18 镜时间线、章节/文字、指针及触控手势 | story-core.mjs、story-renderer.mjs、story-timeline.json、story-layer-manifest.json | 网页/网页/experience.html |
| 故事渲染器 | 按镜头、时间和图层绘制 Canvas 画面与动画 | story-assets/ 中图层 | 网页/网页/story-renderer.mjs |
| 本地静态服务 | 通过 HTTP 提供页面和素材 | Node.js 内置模块 | 网页/网页/server.js |
| QA 与制作工具 | 生成关键画面、检查时间线与原入口资源 | Node.js、Python、PowerShell 脚本及本地依赖 | 网页/网页/tools/、网页/网页/.qa/ |

## 数据流

镜09由 `story-spring.mjs` 提供两套母子图集关节、两位游人的四帧步态和横竖屏布局；原远景百姓仍绘制在背景内。`story-core.mjs` 以 `SPRING_LOW_CUT=.52` 在镜内3.64秒从跟随画面切入独立仰拍背景/母子/花枝，播放器用相同边界设置data-view，竖屏仰拍字幕移至天空留白。低视角母亲手臂只拉伸袖子中段，保留手掌长度。`story-transition.mjs` 用1.35秒花瓣划转遮住镜08末帧到镜09的替换；播放器及制作脚本向渲染器传入时间线，`paintScene` 共用于实时画面和旧镜缓存。暂停跳转跳过转场遮罩。

镜11通过素材清单加载贴年画女子/独立手臂和牡丹年画。`story-renderer.mjs` 的 `newyear` 合成压纸、孩童点灯、灯笼亮起，`story-core.mjs` 定义先推近再拉远的镜头；横竖屏分别排布。图层已齐备用于预览，尚未完成目标设备验收。

镜13通过 `story-layer-manifest.json` 的 `plate-pavilion` 加载独立沉香亭园林背景。运行时已由单张群像改为四位角色各自的透明三姿态图集；`story-pavilion.mjs` 定义图集裁切、头部锚点、动作时序和横竖屏布局，渲染器按镜头内时间合成。原群像与姿态初稿保留为素材来源。该实现尚未通过完整镜头及真实设备验收。

主入口加载本地原站脚本和资源，并叠加项目的牡丹主题素材、文字和样式。分层预览由 story-player.mjs 读取时间线，调用 story-core.mjs 计算当前镜头和进度，再交给 story-renderer.mjs 组合图层；图层文件位置由 story-layer-manifest.json 声明。原始文案和分镜来源记录在 story-timeline.json。

## 运行与部署

在 网页/网页/ 执行 node server.js，通过 http://127.0.0.1:8787/ 访问。必须使用本地 HTTP 服务；网页 README 提醒直接打开 HTML 可能无法加载 WebGL 资源。站点目录未见 package.json，目前的本地服务使用 Node.js 标准模块。生产部署方式尚未记录。
