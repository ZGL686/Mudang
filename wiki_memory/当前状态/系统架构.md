# 系统架构

## 应用入口

index.html → source/main.jsx → features/experience/ExperiencePage：React组织导航、画布DOM和六场阅读；useExperienceEngine 在提交DOM后加载 public/vendor/experience/engine.js。index.html#read-story 或 ?view=reading 使用独立阅读视图。

experience.html → source/story.jsx → features/story/StoryPage + useStoryPlayer：React管理加载、开场、时间、播放、章节、逐字正文、弹窗、音频、滚轮/键盘/指针与生命周期，调用 engine/story-renderer.mjs 及core/pavilion/spring/transition模块绘图。

source/data/story-timeline.json、story-layer-manifest.json 和 source-documents.json 为业务数据。素材清单指向 public/assets/story/layers。source/lib/asset-url.js 管理Vite部署基址，主引擎资源在 public/assets/experience/{fonts,xp}。

## 生命周期与构建

分层页面使用 StrictMode，取消异步图像加载、RAF与事件并释放音频和画布。原WebGL引擎为保留的编译应用，没有完整公开dispose；每个文档仅加载一次，原生跨页导航与体验相关源码整页热重载避免重复初始化。引擎路径/文字/诊断适配由 scripts/lib/adapt-experience-engine.py 确定性生成，图形算法保持。

Vite双HTML入口构建到 dist；默认相对base，开发5173、预览4173，暂无自动生产部署。旧 server.js 仅在 docs/archive/pre-react 归档。

## 目录与制作

materials/documents、images/story-originals、artwork、prompts、references 保存可追溯制作来源；materials/local 保留本地ZIP、原始解包目录与站点快照且Git忽略。scripts/{data,art,qa,lib} 定位根工程并使用项目依赖。Python通过环境或.env.local配置，不在源码存机器路径。

旧QA在 docs/qa/legacy，新工具结果在 docs/qa/current，本轮迁移映射与浏览器范围在 docs/qa/react-migration。历史日志中的旧路径保留原记录；当前目录映射见 docs/STRUCTURE.md。
