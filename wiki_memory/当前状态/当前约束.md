# 当前约束

## 技术约束

- 通过网页目录中的 server.js 提供本地 HTTP；不要把 file:// 双击打开当作完整验收。
- 主入口 index.html 依赖原站 WebGL 代码、模型和素材；保持其原交互与资源关系，除非用户明确要求改动。
- 2D 分层播放器与主入口仍是独立实现，但已用双向链接接通：index.html 的加载页和六场阅读区可打开 experience.html，预览页可返回 index.html#read-story。Codex 浏览器中直接访问 #read-story 未能滚到该区；入口整合不等同于主入口滚动/WebGL 验收。新增场景或动画需以 story-timeline.json、story-layer-manifest.json 和 story-assets/layers/人物动画制作记录.md 为准。
- 站点目录没有 package.json；不要假设已有统一 npm 脚本。

## 兼容性约束

- 桌面与手机素材目录均存在，但当前记录没有完成桌面浏览器及触控验收。不能把素材存在或 HTTP 200 当作交互兼容性证明。
- 用户提供的 18 镜时序总长为 119 秒；改动文案锚点时须同步检查时间线里的原文位置。

## 质量约束

- 六场故事中的历史论断需要权威出处核对；现有网页 README 将这一项列为参赛前工作。
- 依据网页 README，在正式参赛前必须取得原站资源授权，或以团队原创代码和素材替换相应部分。
- browserVerified 当前为 false。只有在目标浏览器上完成实际交互验收后才可更新该状态。

## 操作边界

- 每次有工程改动的完整对话结束时，按 [[决策/ADR-001-按对话提交并推送|Git 决策]] 进行一次Git提交并推送到用户指定的 `https://github.com/ZGL686/Mudang.git`，推送前核对remote。
- 用户已明确授权解决初始化与权限限制；根目录Git已初始化，main与指定origin已配置。本机Git已登录ZGL686，官方API核验push:true；后续通过本机Git提交和推送，无需重复询问初始化或已授予的推送授权。连接器DewMysimple仍为push:false，不影响本机凭据。凭据只交给Windows凭据管理器，提交/推送以实际命令及远端哈希为准。
- 保留用户提供的原始分镜、文案、参考素材和项目快照；不要把它们当作可随意覆盖的生成缓存。
