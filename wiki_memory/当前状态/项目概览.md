# 项目概览

> 面向后续开发的当前摘要；具体实现和状态以来源文件为准。

## 项目名称

牡丹真国色：互动水墨长卷。

## 项目目标

基于用户提供的主线文案和 18 镜分镜制作一部讲述牡丹文化的互动网页作品，内容分为六场。当前并行保留基于原站交互的主入口，以及独立的 2D 分层制作预览。

## 当前阶段

素材与交互持续制作中。主入口与独立 2D 分层预览已加入双向导航；18 镜美术、主入口 WebGL 和真实设备验收仍未完成。现有网页说明明确标记作品不能视为最终参赛版本。

## 主要使用者

制作团队的开发、素材制作和验收流程；项目文件夹名称与网页说明表明作品计划用于数媒比赛展示。正式提交前还需处理原站资源授权和史实出处核对。

## 核心目录

| 路径 | 用途 |
| --- | --- |
| 网页/网页/ | 可运行网页、原交互资源、2D 分镜预览与制作脚本 |
| 网页/网页/story-assets/ | 分层场景素材、清单和人物动画制作记录 |
| 网页/网页/peony-art/ | 图集制作素材与修改前快照 |
| 网页/网页/.qa/ | 资源、图层和画面检查记录 |
| 根目录 Word、ZIP 文件 | 用户提供的主线文案、分镜和参考图源 |

## 重要入口

- 网页/网页/index.html：保留原站交互的主入口。
- 网页/网页/experience.html：独立 2D 分层故事预览，不等同于主入口。
- 网页/网页/server.js：本地静态 HTTP 服务入口；在网页目录执行 node server.js 后访问 http://127.0.0.1:8787/。
- 网页/网页/README.md：运行、素材、版权和已有检查记录。
