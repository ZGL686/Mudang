# 项目概览

牡丹真国色：React + Vite + Canvas 2D 分层水墨叙事。用户于 2026-10-08 明确只保留截图中的分层预览封面与约2分钟入卷播放，并清除冗余、旧站压缩产物和无用代码。当前应用保留六场18镜、119秒时间线、原文及原制作状态。

index.html 默认打开分层封面；experience.html 是原预览地址的兼容入口，两者共用 source/main.jsx → features/story/StoryPage。入卷后保留播放/暂停、进度、六场跳转、环境声和读花史弹窗。旧WebGL主站及独立阅读页面已删除。

public/assets/story 仅保留33张图层、环境声和纸纹。materials 保留故事原文、原图、分层底稿、提示词及用户参考资料；scripts 保留数据与分层QA工具；docs 保存目录说明与当前检查报告。旧编译引擎、专用素材/制作工具、旧实现归档、重复QA产物已清理，可从Git提交2b6d5e8追溯。wiki_memory历史保持。

根目录 npm ci 安装，npm run dev 启动 5173；npm run build 产出 dist，npm run preview 在4173预览。详细路径和命令以 README.md、docs/STRUCTURE.md、package.json 为准。

十八镜artReady仍为false；清理不代表美术、真实设备和参赛验收完成。保留环境声与纸纹的授权及史实出处仍待核验。
