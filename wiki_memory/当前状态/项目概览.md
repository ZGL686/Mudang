# 项目概览

牡丹真国色：六场、18 镜互动水墨长卷。用户于 2026-10-07 明确要求改成 React + Vite 并深度整理目录。工程已以回退后的 9744849 为基线完成迁移，源码统一在 source/，不再存在 网页/网页 嵌套。

根目录 index.html 和 experience.html 分别加载 source/main.jsx 与 source/story.jsx。主入口为 React 界面加保留的 WebGL 图形引擎；分层制作预览为 React 控件加 Canvas 2D 渲染模块。六场与18镜原文、119秒时序及原制作状态保留。

public/assets 保存实际运行素材，public/vendor 保存编译图形引擎；materials 保存用户原文、参考图、底稿与提示词；scripts 保存数据、素材制作与QA工具；docs 保存目录说明、当前QA、历史QA及迁移前实现。wiki_memory 继续遵守现有协议。

根目录 npm ci 安装，npm run dev 启动 5173；npm run build 产出 dist，npm run preview 在4173预览。详细路径和命令以 README.md、docs/STRUCTURE.md、package.json 为准。

原主入口在内置浏览器仍显示纸色空白，尚未确认目标浏览器根因；不把架构迁移或构建通过当作原WebGL、美术、真实设备或参赛验收完成。
